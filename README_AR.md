## حول DNSHE

DNSHE منصة غير ربحية لتوزيع النطاقات، يديرها فريق من الشباب في سنغافورة. نسعى إلى تسهيل نشر المحتوى على الإنترنت من خلال توفير بنية تحتية مجانية وسهلة الاستخدام للنطاقات، للمطورين والطلاب ومحبي البرمجيات مفتوحة المصدر حول العالم.

خدمة النطاقات الأساسية مجانية دائمًا. لا تحتاج إلى بطاقة ائتمان أو معلومات دفع، ولن نفرض إعلانات على نطاقك أو موقعك. يمكنك استخدامها لمدونة شخصية أو معرض أعمال أو مشروع مفتوح المصدر أو نقطة وصول إلى API أو خدمة أتمتة.

يقدم هذا المستودع تعريفًا بخدمة DNSHE وإرشادات التسجيل ومعلومات عن لواحق النطاقات وروابط وثائق API. يتم تسجيل النطاقات وإدارة DNS عبر [لوحة تحكم DNSHE](https://my.dnshe.com/index.php?m=domain_hub).

## المزايا

- **التسجيل والتجديد مجانًا**: لا توجد رسوم خفية للخدمة الأساسية. يمكنك التجديد مجانًا أو الحصول على صلاحية دائمة مجانًا بمساعدة الأصدقاء.
- **أنواع متعددة من سجلات DNS**: تدعم الخدمة A وAAAA وCNAME وMX وTXT وNS وSRV وCAA وغيرها للمواقع والبريد الإلكتروني والتحقق من النطاقات.
- **خوادم أسماء من اختيارك**: استخدم DNSHE DNS أو غيّر NS لتفويض نطاقك إلى مزود DNS خارجي.
- **إدارة موحدة**: أدر النطاقات وسجلات DNS والتجديدات من لوحة واحدة.
- **الأتمتة عبر API**: أدر النطاقات وسجلات DNS من البرامج النصية ومسارات CI/CD وعمليات النشر.

## لواحق النطاقات المتاحة

يعرض الموقع الرسمي حاليًا أربع لواحق موصى بها:

- **<code dir="ltr">.de5.net</code> — التقنية والتطوير**: للمدونات الشخصية ومعارض الأعمال والعروض التجريبية للمشاريع مفتوحة المصدر، مثل <code dir="ltr">myproject.de5.net</code>.
- **<code dir="ltr">.us.ci</code> — التكامل المستمر والخدمات**: لمسارات CI/CD وخدمات SaaS ونقاط وصول API وبيئات الاختبار، مثل <code dir="ltr">myapi.us.ci</code>.
- **<code dir="ltr">.cc.cd</code> — المشاريع الإبداعية**: للعلامات الشخصية واستوديوهات التصميم وعرض الأعمال، مثل <code dir="ltr">portfolio.cc.cd</code>.
- **<code dir="ltr">.bot.cd</code> — الروبوتات والأتمتة**: لروبوتات الذكاء الاصطناعي ومساعدي المحادثة وWebhooks وخدمات الأتمتة، مثل <code dir="ltr">assistant.bot.cd</code>.

هذه الأسماء أمثلة فقط ولا تعني أنها متاحة للتسجيل. راجع لوحة التحكم للاطلاع على اللواحق الأخرى والتوافر الحالي وحصص التسجيل ومتطلبات المراجعة.

## البدء

1. [أنشئ حسابًا مجانيًا](https://my.dnshe.com/register.php)، أو [سجّل الدخول](https://my.dnshe.com/clientarea.php) إذا كان لديك حساب.
2. افتح [Domain Hub](https://my.dnshe.com/index.php?m=domain_hub)، وابحث عن الاسم الذي تريده واختر اللاحقة.
3. سجّل النطاق وأضف سجلات A أو AAAA أو CNAME أو غيرها حسب حاجة مشروعك. يمكنك أيضًا تغيير NS لاستخدام مزود DNS خارجي.
4. اربط النطاق بموقعك أو تطبيقك، ثم اتبع تعليمات مزود الاستضافة لإتمام التحقق وإعداد HTTPS.
5. حافظ على تحديث بريدك الإلكتروني، وانتبه إلى تنبيهات انتهاء الصلاحية وجدّد مجانًا في الوقت المناسب.

## الصلاحية والتجديد

**كون الخدمة مجانية دائمًا لا يعني أن كل نطاق جديد يُعفى تلقائيًا من التجديد.** وفقًا للأسئلة الشائعة في الموقع:

- مدة التسجيل الافتراضية للنطاقات المجانية هي **سنة واحدة**.
- يتاح التجديد المجاني **خلال 180 يومًا قبل انتهاء الصلاحية**.
- انتقل إلى **مركز الميزات ← ترقية النطاق إلى صلاحية دائمة** (Feature Center → Permanent Domain Upgrade) للحصول مجانًا على **صلاحية دائمة دون حاجة إلى التجديد** بمساعدة الأصدقاء.
- تُرسل تذكيرات انتهاء الصلاحية عبر البريد الإلكتروني. وتتوفر تذكيرات Telegram أيضًا عند ربط الحساب وتفعيل الإشعارات.
- قد يُعلّق النطاق أو يُحذف عند مخالفة القواعد، وقد يُحذف إذا لم يُجدّد قبل نهاية فترة الاسترداد التي تلي انتهاء الصلاحية.

راجع لوحة التحكم و[شروط الخدمة](https://www.dnshe.com/tos.html) لمعرفة حالة النطاق وخيارات التجديد وشروط الترقية.
